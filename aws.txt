## Q) Auto Scaling Group (ASG)

```
CPU ↑
   |
   +--> ASG launches new EC2
   |

   |
   +--> ASG terminates EC2
```

Automatically scale EC2 instances based on demand.

## Q&A (Interview Focused)

### Q1. What is a Region vs AZ?

**A:** Region is a geographical area; AZs are isolated data centers within a region.

---

### Q2. Difference between Security Group and NACL?

**A:**

* SG → Stateful, instance-level
* NACL → Stateless, subnet-level

---

### Q3. What is IAM Role?

**A:** Temporary permissions assumed by AWS services (EC2, Lambda).

---

### Q4. How does ALB differ from NLB?

**A:**

* ALB → Layer 7 (HTTP)
* NLB → Layer 4 (TCP)

---

### Q5. What happens when an EC2 fails in ASG?

**A:** ASG automatically replaces it.

---

### Q6. Difference between S3 and EBS?

**A:**

* S3 → Object storage
* EBS → Block storage for EC2

---

### Q7. What is Multi-AZ RDS?

**A:** Synchronous standby replica for high availability.

---

### Q8. What is CloudTrail used for?

**A:** Auditing who did what in AWS.

---

### Q9. What is NAT Gateway?

**A:** Allows private subnet instances outbound internet access.

---

### Q10. What is Serverless?

**A:** No server management (Lambda, DynamoDB).

# 🚀 AWS Services – Interview Notes (With Examples)

🌐 Core Architecture Flow (MOST IMPORTANT)


#####Amazon Route 53

DNS service → converts domain (amazon.com) → IP / Load Balancer
Supports health checks & routing (latency, geo, failover)
* 👉 *Example: If one region (US) goes down, Route53 automatically redirects users to India servers

---

### Amazon CloudFront

* Caches content at edge locations worldwide**
* Reduces latency for global users
* 👉 *Example:* User in India loads website → gets images from Mumbai edge instead of US S3

---

******************************************🔐 Security Layer***************************************

#### AWS WAF (Web Application Firewall)

* Protects from **SQL injection, XSS, bots**
* 👉 *Example:* Blocks malicious requests trying to hack login forms

#### AWS Shield

* Protects from **DDoS attacks**
* 👉 *Example:* Prevents traffic flood that tries to crash your website

---

***************************************🔗 API & Traffic Handling***************************************

### Elastic Load Balancing

* Distributes traffic across multiple servers
* Ensures **high availability**
* 👉 *Example:* 10 users → distributed across 5 EC2 servers

### Amazon API Gateway

* Entry point for APIs
* Supports **auth, throttling, request validation**
* 👉 *Example:* Limit user to 1000 API calls/day

---

***************************************💻 Compute (VERY IMPORTANT)***************************************

### Amazon EC2

* Virtual servers with full control
* 👉 *Example:* Hosting backend of e-commerce website

### AWS Lambda

* Runs code without servers (event-driven)
* 👉 *Example:* Trigger function when file uploaded to S3

### Amazon ECS / AWS Fargate

* Run Docker containers
* Fargate = no server management
* 👉 *Example:* Run microservices in containers

### Amazon EKS

* Managed Kubernetes
* 👉 *Example:* Large-scale apps using Kubernetes clusters

---

***************************************🗄️ Storage (VERY IMPORTANT)***************************************

### Amazon S3

* Stores files (images, videos, backups)
* 👉 *Example:* Store product images of e-commerce site

### Amazon EBS

* Attached to one EC2 (like hard disk)
* 👉 *Example:* Store OS and app data for EC2 

### Amazon EFS

* Shared across multiple EC2s
* 👉 *Example:* Shared files between multiple servers which will be in sync (google drive)

---

***************************************🗃️ Databases (VERY IMPORTANT)***************************************

### Amazon RDS

* Managed SQL DB
* 👉 *Example:* Store user data (name, email, orders)

### Amazon Aurora

* Faster, scalable RDS
* 👉 *Example:* High-traffic apps like banking systems

### Amazon DynamoDB

* Key-value DB, ultra scalable
* 👉 *Example:* Store session data or user activity

---

***************************************⚡ Caching (IMPORTANT)***************************************

### Amazon ElastiCache

* Caches frequently accessed data
* 👉 *Example:* Store product details for fast access

### Amazon MemoryDB

* Durable cache (data persists)
* 👉 *Example:* Real-time apps needing fast + persistent data

---

***************************************🔐 Authentication & Security***************************************

### Amazon Cognito

* User login, signup, token generation
* 👉 *Example:* Login with email/password or Google

### AWS Certificate Manager

* Enables HTTPS
* 👉 *Example:* Secure website (https://)

---

***************************************🔄 Application Integration***************************************

### Amazon SQS

* Message queue (decoupling)
* 👉 *Example:* Order placed → sent to queue → processed later

### Amazon SNS

* Push notifications / alerts
* 👉 *Example:* Send SMS/email for order confirmation

### AWS Step Functions

* Automates workflows
* 👉 *Example:* Order → payment → shipping → notification

---

***************************************📊 Monitoring & Logging***************************************

### Amazon CloudWatch

* Logs, metrics, alarms
* 👉 *Example:* Alert if CPU > 80%

### AWS CloudTrail

* Tracks user actions
* 👉 *Example:* Who deleted an S3 bucket

---

***************************************🚀 CI/CD***************************************

### AWS CodePipeline

* Automates build → test → deploy

### AWS CodeBuild

* Builds code

### AWS CodeDeploy

* Deploys app updates

👉 *Example:* Push code → automatically deployed to EC2

---
